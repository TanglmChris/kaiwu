# 本仓库 .venv 的完整锁定（含传递依赖）。
#
#   uv pip install -r requirements.txt --python .venv/bin/python3
#
# 为什么要有这个文件：`docs/toolchain.md` 以前只列包名不列版本，新机器上
# `uv pip install cocotb` 装到的是当时的最新版。而这里面有三个包能改变测量结果：
#
#   cocotb  —— 驱动激励的那一层：换版本，激励时序 / Timer/Clock 行为 / 波形转储
#              的边沿都可能变 → VCD 变 → sim.total_toggles 变 → sta.dynamic_power_w 变
#   vcdvcd  —— 解析 VCD 算翻转率，换版本等于换读数口径
#   pyyaml  —— 读 params.yaml，决定跑的是哪组参数
#
# 其中 **只有 cocotb 进 `flow` 指纹**（2026-09-14 起，在 `sim` 那项里，见 内部#27 的
# 缺口 3）。**vcdvcd 与 pyyaml 换版本能改数字而指纹一个字不变** —— 这个文件是它们
# 目前唯一的钉子，改动它们的版本等于跨了一个指纹认不出来的边界。
#
# 其余（pytest / pandas / numpy / matplotlib 及其传递依赖）只影响测试与出报告，
# 不进测量路径。
#
# 冻结于 2026-09-14，Linux + Python 3.11.16。产出 flow=64b3c318 那 87 条记录的
# Mac 环境是 Python 3.9.6，且 pytest 8.4.2 / pandas 2.3.3 / numpy 2.0.2 /
