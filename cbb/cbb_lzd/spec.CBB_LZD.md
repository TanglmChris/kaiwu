# CBB_LZD 规格

> 出处：构件库首批落地的 change（2026-10-03 归档，私有）的 D14–D16、D28，用户 2026-09-29 / 2026-09-30 定。

## 功能

在一串比特里找第一个 1：`MSB_EN = 0` 时找**最低位**的 1，`MSB_EN = 1` 时找**最高位**的 1，
输出它的位置与对应的 one-hot；全零由单独的 `o_zero` 报告。常见的「找最小 / 最大」
就是这两个方向。

⚠️ 与早先的 PPA 实验构件 `LZD`（原 `cbb/lzd`，2026-10-02 已删，源码与报告取自 `e6c84bd`）不是同一个构件：`LZD` 从最高位往下数前导零的**个数**、只接受 2 的幂位宽、
只输出计数和全零标志；本构件输出**位置**与 one-hot、位宽任意。`MSB_EN = 1` 时
`o_enc = DAT_W - 1 - (前导零个数)`。

## 接口

| 信号 | 方向 | 位宽 | 含义 |
|---|---|---|---|
| `i_dat` | in | `DAT_W` | 输入（二进制） |
| `o_enc` | out | `ADDR_W` | 找到的那个 1 的位置（bit 下标），`ADDR_W` 比 `$clog2(DAT_W)` 宽时高位为 0；`o_zero = 1` 时无意义 |
| `o_dec` | out | `DAT_W` | 同一位置为 1、其余为 0；`o_zero = 1` 时全 0 |
| `o_zero` | out | 1 | `i_dat == 0` |

## 时序约定

**纯组合**，没有时钟与复位。三个输出之间的关系对任意输入都成立：

- `o_zero = 1` 当且仅当 `i_dat == 0`，此时 `o_dec == 0`。
- `o_zero = 0` 时，`o_dec` 恰有一位为 1，那一位的下标等于 `o_enc`，且 `i_dat[o_enc] = 1`；
  `MSB_EN = 0` 时 `i_dat` 在 `o_enc` 之下全为 0，`MSB_EN = 1` 时在 `o_enc` 之上全为 0。
- `ADDR_W > $clog2(DAT_W)` 时，`o_enc` 的第 `$clog2(DAT_W)` 位及以上恒为 0。
- 不同 `SCHEME` 在 `o_zero = 0` 时输出逐位相同；`o_zero = 1` 时 `o_enc` 可以各不相同，调用方
  MUST NOT 依赖它。

`sim.cycles` 记为 `null`，与 `LZD` 相同。

## 参数

| 参数 | 取值 | 默认 | 含义 |
|---|---|---|---|
| `DAT_W` | >= 2 的任意整数 | 16 | 输入位宽，不限 2 的幂 |
| `ADDR_W` | >= `$clog2(DAT_W)` | `$clog2(DAT_W)` | `o_enc` 的位宽；可以配得更宽以直接接到更宽的地址总线，高位补 0。小于 `$clog2(DAT_W)` 是非法配置，由参数检查（`CBB_PARAM_CHK_ON`）报错 |
| `MSB_EN` | 0 / 1 | 0 | 0：找最低位的 1；1：找最高位的 1。改的是功能，不进扫参（`params.yaml` 标 `sweep: false`） |
| `SCHEME` | 0 / 1 / 2 | 0 | 结构，本构件自己的编号（见下表） |

| `SCHEME` | 名字 | 一句话 |
|---|---|---|
| 0 | `CLA` | 每个下标位一棵独立的进位先行树（时序最好） |
| 1 | `CLA_SHARED` | `CLA` 的共享传播版，门数最少 |
| 2 | `TOOL` | 行为级写法，结构交给综合工具（对照组，面积最小） |

三种取自 `LZD` 的七种里在本仓实测面积-延时前沿上的那几种（`e6c84bd` 的 `cbb/lzd/REPORT.LZD.md`，16/32/64 位）。
本构件**不例化 `LZD`**，三种结构都在本模块内展开（2026-09-30 用户定：CBB 内部尽量不例化其它模块）。

位宽不是 2 的幂时高位补 0 到 2 的幂、按 `MSB_EN` 反转位序，再把前导零计数换算成位置 —— 这些属于实现，
写在本文件的「实现要点」。

## 实现要点

- 输入高位补 0 到 2 的幂 `PAD_W`；找最低位的 1 时先反转位序，统一成「从最高位数前导零」，位置 = 计数（`MSB_EN = 0`）或计数按位取反（`MSB_EN = 1`，因为 `PAD_W - 1 - cnt = ~cnt`）。`o_dec` = `{0…0, ~zero} << pos`。
- 三种结构取自 `LZD`（`e6c84bd` 的 `cbb/lzd`；Dimitrakopoulos 2008 图 4 / 图 5 与行为级对照），在本模块内展开（D28、add-rtl-coding-style 的 D25）：
  - OR 树 `orp`：第 k 层起点 `2*PAD_W - (2*PAD_W >> k)`。
  - 第 i 个计数位的进位树有 M = `PAD_W >> (i+1)` 组；第 m 层第 j 组的 `g` 在 `2M - (2M >> m) + j`，`p`（只有 j >= 1 的组有）在 `2M - (2M >> m) - m + j - 1` —— 这样 `p` 没有「最低组无驱动、无读者」的空洞，不需要 lint 豁免。
  - `TOOL` 是逐位扫描的与或链，等于行为级 for 循环展开后的电路（D10 不允许 `always @(*)` 里写循环）。
- 打平之后综合没有层级可保，工具会重排结构；这几种结构的 PPA 差异比 `LZD` 的报告（`e6c84bd` 的 `cbb/lzd/REPORT.LZD.md`）里的小。

## 不做

- 找第 k 个 1、找所有 1（popcount 类）。
- 流水：纯组合，和前后级拼在同一拍里用。
