# CBB_BIN2ONEHOT 规格

> 出处：构件库首批落地的 change（2026-10-03 归档，私有）的 D31–D32，用户 2026-09-30 定。

## 功能

二进制编号转 one-hot：`i_bin < DAT_W` 时 `o_oh` 只有第 `i_bin` 位为 1；`i_bin >= DAT_W` 时全 0。
典型用途：把归还的缓冲区编号、存储写入的表项号转成 one-hot。与 `CBB_ONEHOT2BIN` 互逆。

## 接口

| 信号 | 方向 | 位宽 | 含义 |
|---|---|---|---|
| `i_bin` | in | `ADDR_W` | 二进制编号 |
| `o_oh` | out | `DAT_W` | 第 `i_bin` 位为 1、其余为 0；`i_bin >= DAT_W` 时全 0 |

## 时序约定

**纯组合**，没有时钟与复位。**不带使能**：编号无效的拍要全 0 时，调用方自己把 `o_oh` 与上有效。

- `i_bin < DAT_W` 时 `o_oh` 恰有一位为 1，下标等于 `i_bin`。
- `i_bin >= DAT_W` 时 `o_oh == 0`（`DAT_W` 不是 2 的幂，或 `ADDR_W` 比 `$clog2(DAT_W)` 宽时会出现）。

`sim.cycles` 记为 `null`。

### 断言

| # | 断言 |
|---|---|
| A1 | `o_oh` 为全 0 或恰有一位为 1 |
| A2 | `i_bin < DAT_W` ⇔ `o_oh != 0` |
| A3 | `i_bin < DAT_W` 时 `o_oh[i_bin] = 1` |

## 参数

| 参数 | 取值 | 默认 | 含义 |
|---|---|---|---|
| `DAT_W` | >= 2 的任意整数 | 16 | 输出位宽，不限 2 的幂 |
| `ADDR_W` | >= `$clog2(DAT_W)` | `$clog2(DAT_W)` | `i_bin` 的位宽；可以配得更宽以直接接更宽的编号，超出 `DAT_W` 的取值输出全 0。小于 `$clog2(DAT_W)` 是非法配置，由参数检查（`CBB_PARAM_CHK_ON`）报错 |

结构只有一种（译码器），不设 `SCHEME`。

## 实现要点

- `o_oh = {{(DAT_W-1){1'b0}},1'b1} << i_bin`：逻辑左移的移位量不小于位宽时结果为 0，于是
  `i_bin >= DAT_W` 的全 0 不需要单独的比较；译码器的结构交给综合工具（与 `CBB_LZD` 的 `o_dec` 同一写法）。
- 只有一种结构，不设 `SCHEME`；不例化其它模块（add-rtl-coding-style 的 D25）。

## 不做

- 使能输入：调用方自己与上有效（用户 2026-09-30 选）。
- 多个编号同时译码（多热输出）。
