# CBB_ONEHOT2BIN 规格

> 出处：构件库首批落地的 change（2026-10-03 归档，私有）的 D29–D30，用户 2026-09-30 定。

## 功能

one-hot（或全 0）转二进制编号：`i_oh` 只有第 k 位为 1 时 `o_bin = k`，全 0 时 `o_bin = 0`。
典型用途：把命中向量转成表项号。与 `CBB_BIN2ONEHOT` 互逆。

## 接口

| 信号 | 方向 | 位宽 | 含义 |
|---|---|---|---|
| `i_oh` | in | `DAT_W` | one-hot 或全 0 的输入 |
| `o_bin` | out | `ADDR_W` | 为 1 的那一位的下标；`ADDR_W` 比 `$clog2(DAT_W)` 宽时高位为 0 |

## 时序约定

**纯组合**，没有时钟与复位。输出对任意输入由下面的公式定义：

- `o_bin` 的第 i 位（i < `$clog2(DAT_W)`）= 下标的第 i 位为 1 的那些 `i_oh` 位之或。
- `i_oh` 是 one-hot 时，`o_bin` 等于那一位的下标；`i_oh == 0` 时 `o_bin == 0`。所以「全 0」与
  「第 0 位为 1」输出相同，调用方要区分时自己看 `|i_oh`。
- `i_oh` 有多位为 1 时，输出仍按公式（各下标按位或），但不是任何一位的编号，调用方 MUST NOT 依赖它。
- `ADDR_W > $clog2(DAT_W)` 时，`o_bin` 的第 `$clog2(DAT_W)` 位及以上恒为 0。

`sim.cycles` 记为 `null`。

### 断言

| # | 断言 |
|---|---|
| A1 | `i_oh` 是 one-hot 时 `i_oh[o_bin] = 1` |
| A2 | `i_oh == 0` 时 `o_bin == 0` |
| A3 | `o_bin` 的第 `$clog2(DAT_W)` 位及以上恒为 0 |

## 参数

| 参数 | 取值 | 默认 | 含义 |
|---|---|---|---|
| `DAT_W` | >= 2 的任意整数 | 16 | 输入位宽，不限 2 的幂 |
| `ADDR_W` | >= `$clog2(DAT_W)` | `$clog2(DAT_W)` | `o_bin` 的位宽；可以配得更宽，高位补 0（同 `CBB_LZD`）。小于 `$clog2(DAT_W)` 是非法配置，由参数检查（`CBB_PARAM_CHK_ON`）报错 |

结构只有一种（每个输出位一棵或树），不设 `SCHEME`。

## 实现要点

- 每个输出位 `o_bin[i]` 是一棵或树：`|(i_oh & f_idx_mask(i))`，掩码由常量函数 `f_idx_mask` 在 elaboration 期算出（下标第 i 位为 1 的那些位置为 1），综合后只剩或门。整个向量参与与运算，第 0 位（任何掩码都不含它）也就不会被 lint 报「没有使用」，不需要豁免。
- 高位（`i >= $clog2(DAT_W)`）直接接 0。
- 只有一种结构，不设 `SCHEME`；不例化其它模块（add-rtl-coding-style 的 D25）。

## 不做

- 检查输入是不是 one-hot、输出有效位：调用方需要时自己算 `|i_oh` 或 `$onehot0`。
- 优先级：多热输入不挑其中一位，要挑用 `CBB_LZD`。
